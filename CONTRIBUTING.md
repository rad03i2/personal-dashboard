# Contributing / المساهمة

Thanks for improving Personal Dashboard. Keep contributions privacy-first, dependency-light, accessible, and focused on functionality that works entirely in the browser.

1. Fork the repository and create a focused branch.
2. Run `npm test` before submitting changes.
3. Add or update tests for domain logic.
4. Do not add telemetry, remote services, secrets, generated bundles, or unnecessary dependencies.
5. Keep README claims aligned with implemented behavior.

## العربية
نرحب بالمساهمات. حافظ على الخصوصية والعمل المحلي وخفة الاعتماديات وإمكانية الوصول. شغّل `npm test`، وأضف اختبارات لأي منطق جديد، ولا تضف تتبعًا أو خدمات خارجية أو أسرارًا أو ملفات مولدة غير ضرورية.
